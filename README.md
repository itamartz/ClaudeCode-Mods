# ClaudeCode-Mods

A Claude Code plugin marketplace of personal mods: hooks, panes and commands that change Claude Code's own interface and behaviour. The marketplace is named `claudecode-mods` and is defined in `.claude-plugin/marketplace.json`.

## Mods

| Mod | Description |
|---|---|
| [`athena-progress`](progress/README.md) | A `/progress` pane listing task progress read from `AthenaDev/progress/*.json` |

## Installing a mod

1. Push this repository to GitHub as `itamartz/ClaudeCode-Mods`.
2. In a Claude Code terminal session, run:

   ```
   /plugin install athena-progress --marketplace itamartz/ClaudeCode-Mods
   ```

   Answer `y` to add the marketplace, then pick a scope. Choose **user** so the mod applies on every project.
3. To update later, refresh the marketplace and the plugin, then reload:

   ```
   /plugin marketplace update claudecode-mods
   claude plugin update athena-progress
   /reload-plugins
   ```

4. For local development without GitHub, run Claude Code from the mod's folder:

   ```
   claude --plugin-dir <repo>\progress
   ```

5. To configure an installed mod, use the config menu (`/config`) or set its options under `pluginConfigs` in settings, keyed by the mod's name. See each mod's README for its options.

## Adding a new mod

1. Create a new folder at the repository root holding `.claude-plugin/plugin.json` and a `hooks/` folder.
2. Add an entry for it to `.claude-plugin/marketplace.json`:

   ```json
   { "name": "<mod>", "source": "./<folder>" }
   ```

3. Validate the marketplace, manifests and hooks from the repository root:

   ```
   claude plugin validate .
   ```

4. Run the mod's tests:

   ```
   claude plugin test <folder>
   ```

## Generated files

`.claude-plugin/types/` inside a mod is generated by Claude Code when the mod loads and is git-ignored.
